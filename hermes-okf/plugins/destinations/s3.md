# S3 Destination

Concrete implementation of [Generic Object Storage](/plugins/destinations/generic-object-storage.md) for AWS S3.

## Entry Point

```toml
[project.entry-points."hermes_plugins.destinations"]
s3 = "s3_destination:S3Destination"
```

**Type in YAML config:** `s3`

## Class: `S3Destination`

Extends `ObjectStorageDestination`. Sets `prefix = "s3:/"` so that `fsspec` routes writes to S3.

### Dependencies

- `s3fs` (for S3 filesystem access via fsspec)
- `generic_object_storage_destination` (base class)

### Configuration

Inherits from [Generic Object Storage](/plugins/destinations/generic-object-storage.md):

| Key      | Description            | Required |
|----------|------------------------|----------|
| `format` | Output file format     | yes      |
| `bucket` | S3 bucket name         | yes      |
